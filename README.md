# JanDrishti 🏙️

## Citizen-Verified Civic Issue Resolution Platform

> **Report. Resolve. Verify.**

JanDrishti is a web-based civic technology platform designed to improve transparency, citizen participation, and accountability in the resolution of local civic issues.

The platform allows citizens to report civic problems such as damaged roads, broken streetlights, water leakage, waste accumulation, blocked public spaces, and other local infrastructure issues. Administrators can review and manage these reports, update their progress, and submit evidence after taking action.

The key feature of JanDrishti is **citizen verification of the claimed resolution**.

Instead of considering an issue completely resolved merely because an administrator changes its status to "Resolved", JanDrishti allows the citizen to verify the result and either confirm the resolution or request that the issue be reopened.

---

# 📌 Project Overview

Civic issue reporting platforms generally provide a way for citizens to submit complaints and track their status. However, the process can become less transparent once an issue is marked as resolved.

JanDrishti focuses on this final stage of the civic issue lifecycle:

> **Was the reported problem actually resolved?**

The platform therefore introduces an additional verification layer between **"Resolved by Authority"** and **"Closed"**.
